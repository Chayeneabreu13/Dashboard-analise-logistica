# 📊 Dashboard de Análise Logística | Power BI

## 📌 Sobre o Projeto

Projeto de análise de dados logísticos desenvolvido no Power BI, com foco na visualização de indicadores de desempenho e na identificação de informações relevantes para a gestão de entregas.

A análise explora o comportamento das operações logísticas, permitindo acompanhar prazos, desempenho das equipes, canais de distribuição e distribuição das entregas.

O projeto utiliza dados fictícios para fins de estudo e desenvolvimento de habilidades práticas em Business Intelligence.

## 🎯 Objetivo

Desenvolver uma visão analítica das operações logísticas, facilitando a interpretação dos dados e o acompanhamento de indicadores estratégicos.

## 📈 Indicadores Analisados

- Total de entregas realizadas.
- Total de entregas dentro do prazo.
- Entregas no prazo por canal de distribuição.
- Percentual de entregas por equipe.
- Evolução mensal das entregas.
- Desempenho dos vendedores.
- Entregas com atraso por cidade.
- Distribuição das entregas por status.

## 🛠️ Tecnologias e Ferramentas

## 🔎 Análises Desenvolvidas

O dashboard reúne informações importantes para compreender o desempenho das operações logísticas.

As visualizações permitem analisar a distribuição das entregas, acompanhar o comportamento mensal, identificar cidades com atrasos e observar o desempenho dos canais e equipes.
